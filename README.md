# github-project-dashboard

Dashboard client branché sur GitHub Projects : un Gantt des sujets en cours, et deux actions, déclarer un bug ou une urgence, proposer une idée.

Le projet en est au cadrage. La PRD se trouve dans [`docs/superpowers/specs/2026-10-15-dashboard-client-gh-projects-design.md`](docs/superpowers/specs/2026-10-15-dashboard-client-gh-projects-design.md).

Stack prévue : Rust (Loco), React + shadcn/ui, SQLite, Docker (image GHCR).
