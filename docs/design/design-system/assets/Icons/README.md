Icônes Tabler (outline, licence MIT), une par concept de l'interface. Ce sont des tracés monochromes dont l'encre est `currentColor`. Affichées en `<img>`, elles apparaissent donc en noir. Dans le produit, elles s'insèrent en ligne via `@tabler/icons-react`, pour hériter de la couleur du texte ou du token (`active-strong` pour Sujet, `danger-strong` pour Bug, `idea-strong` pour Idée).
